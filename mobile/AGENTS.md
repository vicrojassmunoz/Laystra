# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

Pinned to SDK 54, not the latest (57), because the App Store's Expo Go client hadn't caught up to SDK 57 yet as of 2026-08-09 (Apple review lag after a new SDK release). Don't bump this back to latest without checking Expo Go's current App Store SDK support first — `npx expo install expo@latest && npx expo install --fix` otherwise reintroduces the "update Expo Go" error on-device.
