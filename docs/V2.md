# v2 — Backup, Hoy colapsable, ejercicios, CSV

**Estado: ENTREGADO** (2026-08-30, código + tests). Ítems movidos a [CHANGELOG.md](CHANGELOG.md). Roadmap actualizado en [ROADMAP.md](ROADMAP.md).

Pasos manuales que quedan en tu máquina: registrar Task Scheduler (`.\scripts\backup_db.ps1 -RegisterTask`) y correr un `-VerifyOnly` contra la primera copia; si usas el build EAS `preview` (no Expo Go), hay que reconstruirlo para que "Exportar CSV" encuentre los módulos nativos.

## Objetivo de una línea
Proteger el histórico (`laystra.db`), aligerar Hoy tras guardar, poder crear ejercicios desde la app (y añadirlos al editar un entreno pasado), y exportar entrenos a CSV.

## Fuera de alcance (v2)
Todo lo que sigue en `ROADMAP.md` fuera de este bloque — en particular PR por volumen (#1), `notes` (#6), timer/asistencia (#7/#8), rediseño de la tab bar (#10), HealthKit, IA. El backup no sustituye producción en el primer ensayo de restauración (solo integridad de una copia). Crear ejercicio no incluye editar/borrar el catálogo (`PUT`/`DELETE /exercises` no existen).

## Modelo de datos nuevo
Ninguno. `POST /exercises` y `PUT /workouts/{id}` ya cubren #3 y #4. El CSV es una proyección de `Workout`/`WorkoutSet`/`Exercise` existentes.

## Endpoints nuevos
```
GET    /workouts/export     text/csv UTF-8 con BOM; una fila por WorkoutSet
                            (date, exercise, weight, reps, set_order, unit, superset_group)
```
`POST /exercises` ya existía (201, `muscle_group_primary` obligatorio; `name` no puede ir en blanco). Detalle en `backend/docs/ARCHITECTURE.md`.

## Infra nueva
- `backend/scripts/backup_db.ps1` — hot backup del volumen Docker `laystra-db` → `%OneDrive%\Laystra-backups\`.
- `backend/scripts/restore_db.ps1` — restauración manual (stop backend, copiar, start).
- Task Scheduler diario ~03:00 (registro one-shot, ver `backend/README.md`).

## Pantallas afectadas
1. **Hoy** (`TodayScreen.tsx`) — tras guardar, tarjetas de ejercicio (y superseries) colapsadas; tap reexpande.
2. **Picker de ejercicios** (`ExercisePickerList.tsx`) — "+ Nuevo ejercicio" en Rutinas, Hoy, Progreso, Historial.
3. **Historial** (`HistorialScreen.tsx`) — añadir ejercicio al editar un entreno; botón "Exportar CSV".
